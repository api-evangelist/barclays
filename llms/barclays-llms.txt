# Barclays

> Barclays is a UK-headquartered multinational bank. Its public API surface is the Barclays API Exchange at developer.barclays.com, which publishes 30 API versions across three distinct families: UK Open Banking (OBIE Read/Write v3.1 and v4.0), Barclays Bank Ireland (Berlin Group NextGenPSD2), and Barclaycard US card servicing. 26 of them publish a machine-readable OpenAPI 3.1 contract covering 184 operations. Nothing is callable anonymously: every API requires registration, access approval, an OAuth 2.0 token, and — on the UK Open Banking surface — an Open Banking-issued mTLS transport certificate.

## Contracts

Barclays serves a real OpenAPI 3.1 export for every catalogued API version at `https://developer.barclays.com/api/apis/versions/{apiVersionId}/design?specification=oas31` (Swagger 2.0 and OpenAPI 3.0 exports are available at the same path with `specification=swagger2` / `oas3`). The version identifiers come from `https://developer.barclays.com/api/apis`, which is anonymous and returns the whole catalogue.

## Conventions an agent needs

- **Auth**: OAuth 2.0. UK Open Banking uses `TPPOAuth2Security` (client_credentials, scopes `accounts`/`payments`/`fundsconfirmations`/`openid`) and `PSUOAuth2Security` (authorization_code, PSU SCA). Barclaycard US uses `ExternalTiaaUsCCAuth` (client_credentials). See `authentication/` and `scopes/`.
- **Correlation**: three different headers for three families — `x-fapi-interaction-id` (UK Open Banking), `X-Request-ID` (Barclays Bank Ireland), `Correlation-ID` (Barclaycard US).
- **Idempotency**: `x-idempotency-key` on 19 of 64 mutating operations, all of them in Payment Initiation and Variable Recurring Payment. No other write in the estate has replay protection, and no key-retention window is published.
- **Errors**: `OBErrorResponse1 { Id, Code, Message, Errors[] }` with `OBError1 { ErrorCode, Message, Path, Url }`; `ErrorCode` values are `UK.OBIE.*` strings. Not RFC 9457.
- **Rate limits**: 99 operations declare HTTP 429 but Barclays publishes no numeric limit, no window and no `Retry-After` or `RateLimit-*` response header.
- **Reversibility**: every reversal Barclays publishes is a consent revocation. No operation cancels, refunds, voids or reverses an executed payment, and no window is stated.
- **Pagination**: OBIE `Links` (Self/First/Prev/Next/Last) plus `Meta.TotalPages` on UK Open Banking collections. The open-data APIs support `If-None-Match`/`Etag` conditional GETs instead.

## Not published

- No SDK on any registry, in any language. No CLI. No embeddable components.
- No MCP server and no A2A agent card.
- No AsyncAPI, though the Event Notification API is a real event surface (push callbacks plus aggregated polling).
- No changelog, no deprecation or sunset policy, no status page, no published pricing.
- No `llms.txt`, no `/.well-known/api-catalog`, no OpenID discovery document on any Barclays host. `security.txt` is served on barclays.com, home.barclays, www.barclays.co.uk and www.barclaycard.co.uk.
